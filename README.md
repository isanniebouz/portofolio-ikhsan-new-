## 🚀 Cara Menjalankan Website Secara Lokal

### Cara 1: Langsung Buka di Browser
Cukup klik ganda (double click) file `index.html` pada File Explorer Anda di folder `c:\portfolio.isan`. Website akan langsung terbuka di browser (Chrome, Edge, Firefox, dll).

### Cara 2: Menggunakan Live Server di VS Code
1. Buka folder `c:\portfolio.isan` di Visual Studio Code.
2. Pasang ekstensi **Live Server** (bila belum terpasang).
3. Klik kanan pada `index.html` dan pilih **"Open with Live Server"**.

---

## 🌐 Cara Mengunggah (Deploy) ke Internet Gratis

Anda dapat membagikan link portofolio ini kepada guru, teman, atau perusahaan tempat magang (PKL) melalui platform gratis berikut:

### Opsi A: Vercel (Paling Cepat & Mudah)
1. Kunjungi [vercel.com](https://vercel.com) dan masuk menggunakan akun GitHub.
2. Unggah repositori folder `portfolio.isan`.
3. Klik **Deploy**. Website Anda akan langsung aktif dengan domain gratis seperti `ikhsan-portfolio.vercel.app`.

### Opsi B: GitHub Pages
1. Buat repositori baru di GitHub dengan nama misalnya `portfolio` atau `ikhsan-portfolio`.
2. Push seluruh file di dalam `c:\portfolio.isan` ke repositori tersebut.
3. Buka tab **Settings** > **Pages** di repositori GitHub Anda.
4. Pada bagian Branch, pilih `main` atau `master` dan klik **Save**.
5. Website Anda dapat diakses di `https://username.github.io/portfolio`.
